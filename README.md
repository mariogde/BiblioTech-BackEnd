# 📚 BiblioTech - Back-End

API RESTful para gerenciamento de biblioteca desenvolvida em **Spring Boot**. O sistema centraliza o controle do acervo de livros e o cadastro de usuários.

---

## 🛠️ Tecnologias

- **Java**
- **Spring Boot**

---

## 📌 Funcionalidades Principais

- 📖 **Gestão de Acervo:** Cadastro, listagem, atualização e remoção de livros.
- 👥 **Gestão de Usuários:** Cadastro e controle de leitores/membros.
